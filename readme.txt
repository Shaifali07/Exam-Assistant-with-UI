AI Question Paper Generator

This project is an AI-based system that generates structured university-level question papers based on given inputs such as subject, syllabus, course outcomes (COs), and instructions.
It ensures academic alignment by integrating Course Outcome mapping and Bloom’s Taxonomy levels into the generated paper.

Features
Generate complete question papers using AI
Course Outcome (CO) mapping for each question
Bloom’s Taxonomy level tagging
Structured JSON-based output
Tabular formatted question paper
Streamlit-based user interface

Input Parameters
Subject name
Course Outcomes (COs)
Syllabus topics
Exam instructions (marks, sections, etc.)

Output
Fully structured question paper
CO mapping for each question
Bloom’s level classification
Clean and readable format

Tech Stack
Python
Streamlit
OpenAI / LLM-based prompt system
JSON formatting

Purpose
To automate and standardize the process of question paper generation while ensuring alignment with academic frameworks like COs and Bloom’s Taxonomy.

How to Run
Clone the repository
Install dependencies
Run Streamlit app
Provide inputs and generate paper
